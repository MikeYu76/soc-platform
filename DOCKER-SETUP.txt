SOC Platform Docker Setup

FILES TO COPY
Copy Dockerfile, compose.yaml, .dockerignore, requirements.txt, and .env.docker.example into the top-level soc-platform project folder. They sit beside api, application, and tests. Keep the filenames exactly as shown. Open this guide from the ZIP; it does not need to go into the project.

SET UP SECRETS
If you already have a .env file from setting up authentication, keep it. Open it and add this new line using a strong password of your choice:
   OPENSEARCH_INITIAL_ADMIN_PASSWORD=your_strong_opensearch_password
Use a different password from the bootstrap administrator password.

If you do not already have a .env file, copy .env.docker.example and name the copy .env. Replace every placeholder. The JWT secret can be generated in PowerShell with:
   .\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(48))"
The bootstrap administrator password must be at least 12 characters. Do not share or commit .env.

START
Open PowerShell in the soc-platform project folder and run:
   docker compose up --build -d

OPEN
API documentation: http://localhost:8000/docs
API health:       http://localhost:8000/health
OpenSearch:       https://localhost:9200 (a self-signed certificate warning is expected for this local development setup)
Dashboards:       http://localhost:5601
OpenSearch login: admin and the OPENSEARCH_INITIAL_ADMIN_PASSWORD from .env

All published Compose ports bind to localhost; other computers on the network cannot reach these services through the host ports.

STOP
   docker compose down

PostgreSQL data is kept in the postgres-data Docker volume, and OpenSearch data is kept in the opensearch-data volume. Stopping or recreating the containers keeps them. To stop the services and permanently erase both stored data volumes, run:
   docker compose down -v

NOTES
Processed events are indexed to the OpenSearch security-events index after the relational database commit. In OpenSearch Dashboards, open Discover, create a data view named security-events, and choose timestamp as the time field. A durable relational outbox retries indexing failures. Administrators can inspect queue status and Prometheus-format aggregate metrics through the authenticated operations endpoints. A sustained backlog alert is logged using the threshold and duration settings in .env. The API container runs non-root with a read-only root filesystem and restricted capabilities. This Compose file is for local development and does not configure production TLS, managed secrets, or production operations.
